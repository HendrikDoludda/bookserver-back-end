# 09 Metadata enrichment — hand checks

## Step 6 · Candidates endpoint (asks the real AniList)
- [ ] Stop the server and start it again with `cargo run` — the new route is compiled in
- [ ] Log in: `curl -s -X POST http://127.0.0.1:8080/api/v1/auth/login -H 'Content-Type: application/json' -d '{"username_or_email":"PASTE_USERNAME","password":"PASTE_PASSWORD","device_name":"curl","platform":"macos"}' -w '\n'` — `PASTE_USERNAME` / `PASTE_PASSWORD` are your admin account's. Keep `session_token` from the answer (not `refresh_token`). If it answers `"status":"totp_required"` instead, send `curl -s -X POST http://127.0.0.1:8080/api/v1/auth/login/totp -H 'Authorization: Bearer PASTE_CHALLENGE_TOKEN' -H 'Content-Type: application/json' -d '{"code":"PASTE_APP_CODE"}' -w '\n'` with `challenge_token` from the first answer and the six digits your authenticator app shows now (not a recovery code), and keep `session_token` from that answer
- [ ] `curl -s -X POST http://127.0.0.1:8080/api/v1/libraries -H 'Authorization: Bearer PASTE_SESSION_TOKEN' -H 'Content-Type: application/json' -d '{"name":"Manga test","library_type":"manga"}' -w '\n'` answers a library — keep its `id` as `PASTE_LIBRARY_ID`
- [ ] `curl -s http://127.0.0.1:8080/api/v1/series -H 'Authorization: Bearer PASTE_SESSION_TOKEN' -w '\n'` lists your series — keep the `id` of one, best a manga, as `PASTE_SERIES_ID`
- [ ] `curl -s -X PUT http://127.0.0.1:8080/api/v1/libraries/PASTE_LIBRARY_ID/series/PASTE_SERIES_ID -H 'Authorization: Bearer PASTE_SESSION_TOKEN' -w '%{http_code}\n'` answers `204` — the series is now also in the manga library
- [ ] `curl -s http://127.0.0.1:8080/api/v1/series/PASTE_SERIES_ID/metadata/candidates -H 'Authorization: Bearer PASTE_SESSION_TOKEN' -w '\n'` answers `"provider":"anilist"`, `"query"` with the series' name, and up to ten candidates — descriptions without `<br>` or other tags, and `"exact_match":true` on one whose title is the name, if AniList has it
- [ ] The same command with `?query=shingeki%20no%20kyojin` after `candidates` answers "Attack on Titan" first, with `"exact_match":true` — matched by its romaji title, which is under `alternative_titles`
- [ ] The same command with `?query=` after `candidates` answers `{"error":"invalid_query"}`
- [ ] `sqlite3 "$HOME/Library/Application Support/com.hendrikdoludda.bookserver/app_data.sqlite" "SELECT provider, request_key FROM metadata_cache"` lists `anilist` with `search:` and your series' name in lowercase, and `search:shingeki no kyojin` — the answers kept for the next 30 days
- [ ] Clean up: `curl -s -X DELETE http://127.0.0.1:8080/api/v1/libraries/PASTE_LIBRARY_ID/series/PASTE_SERIES_ID -H 'Authorization: Bearer PASTE_SESSION_TOKEN' -w '%{http_code}\n'` and then `curl -s -X DELETE http://127.0.0.1:8080/api/v1/libraries/PASTE_LIBRARY_ID -H 'Authorization: Bearer PASTE_SESSION_TOKEN' -w '%{http_code}\n'` each answer `204`; the series and its books stay
